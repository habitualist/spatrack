# Spatrack Vue Website

Updated to align with the client brief:
- Real Spatrack contact details
- Home, About, Services, Portfolio, Contact
- Added project detail pages
- Sky blue / navy / white styling
- SEO titles and meta descriptions
- Contact form currently opens the user's email app via mailto

## Run locally
npm install
npm run dev

## Build
npm run build

## Important note
For a truly direct working contact form on the live website, connect a real form service such as Formspree, EmailJS, Resend, or a backend endpoint.
